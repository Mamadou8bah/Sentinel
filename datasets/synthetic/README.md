# Synthetic documents (no real PII)

Generate mock IDs, cheques, and invoices with templates + variable fields.

| Subfolder | Purpose |
|-----------|---------|
| `ids/` | Mock ID cards for KYC demo |
| `cheques/` | Genuine + forged samples for document fraud demo |
| `invoices/` | OCR / fraud samples (or use SROIE externally) |

This is the standard, defensible student-project approach and supports the GDPR note in `docs/nfr.md`.
